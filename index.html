¡Bienvenido a mi Proyecto Final de JavaScript!

Este proyecto simula un sistema de alquiler de vehículos desarrollado con HTML, CSS y JavaScript puro. Integra eventos, DOM dinámico, almacenamiento local y cálculos automáticos de descuentos.

Ir al simulador Ver código en GitHub

Sobre el proyecto

Este simulador permite elegir un vehículo del catálogo, definir la cantidad de días de alquiler y calcular automáticamente el costo total, aplicando descuentos del 5% para reservas de 3 a 6 días y del 10% a partir de 7 días.

Los datos se almacenan en LocalStorage para mantener las reservas incluso al recargar la página. También se implementan librerías externas como SweetAlert2 y Toastify para mejorar la interacción y el diseño de los mensajes.
